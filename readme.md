# Calculadora - Clase 5 GitHub Foundations

Este proyecto es una calculadora básica creada como parte de la clase 5 del curso "GitHub Foundations".

## Características

- Operaciones básicas: suma, resta, multiplicación y división.
- Interfaz sencilla y fácil de usar.

## Requisitos

- Python 3.x (si el proyecto está basado en Python).
- Cualquier otro requisito necesario.

## Instalación

1. Clona este repositorio:
    ```bash
    git clone https://github.com/tu-usuario/calculadora.git
    ```
2. Navega al directorio del proyecto:
    ```bash
    cd calculadora
    ```

## Uso

1. Ejecuta el programa:
    ```bash
    python calculadora.py
    ```
2. Sigue las instrucciones en pantalla para realizar cálculos.
